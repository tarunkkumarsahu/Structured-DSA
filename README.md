## Repository Structure

- **Array_Fundamentals/** — completed array problems and topic README

- **Collage_Programs/** — college-related Java programs

## Learning Approach

The goal is not to memorize code. Each problem is used to practice building the logic, understanding why the solution works, and being able to reproduce or adapt it later.
